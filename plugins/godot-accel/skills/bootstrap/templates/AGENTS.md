# Agents

This project is developed with Claude Code and the {{KIT_NAME}} kit, but any AI agent can
continue it. Read, in order:

1. `CLAUDE.md` — project rules, layout, workflow, hard rules. They apply to every agent.
2. `.claude/rules/*.md` — rules for code, scenes, docs, git and working with the user.
3. `.claude/memory/MEMORY.md` and every file it links — working rules learned from the user.
4. `docs/STATUS.md` — where work stopped and what is next.
5. `docs/plans/roadmap.md` — the build order (tick tasks off as they land).
6. `docs/systems/` — what each system does now; `docs/guides/quirks.md` before debugging.

The full read order: `docs/guides/llm-handoff.md`. Commit only on the user's yes; never commit
secrets.
