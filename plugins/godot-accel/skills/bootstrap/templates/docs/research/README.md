# Research

What good looks like for this game, and what the project already holds. Name this folder in every
brief to a subagent and in every plan: the rules say how to work, this says what the work is for.

One page per reference work or topic, `<topic>.md`, listed below. A page says what the reference
does well, the rules it follows (in its own words where it states them), and what this game takes
from it and leaves out. Reference images are study-only: they go in `docs/research/img/` (Godot
ignores `docs/`) and never ship.

**What the project holds:** before making a look, an asset or a placeholder, list what is already
here that could drive it (assets, data fields, reference pages) and say which you use. Keep that
list on the topic's page, under "Held".
