# Standards

The one-page standard for things that must stay consistent (look, feel, sizes, naming). Agreed
row by row with the user. **A locked row beats any plan or STATUS line**; if they disagree, say
so and ask. Read this before planning or building anything it covers.

Status: **locked** (the user agreed) · **proved** (built and checked; locks once the user sees it
in the real thing) · **proposed** (waiting for the user) · **open** (not decided) · **later** (set
by a named later step).
