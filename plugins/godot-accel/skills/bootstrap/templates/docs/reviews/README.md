# Reviews

Read-only audit reports: `YYYY-MM-DD-<kind>.md` (`workflow`, `design`, `tech`, `fun`…), written
by the `project-audit` skill or a reviewer agent. Each has a five-line summary, a ranked top-10
table (problem, one-line fix, effort S/M/L), the detail by section, and "Keep as is". The
user's answers to its questions go into a decision record, not back into the report.
