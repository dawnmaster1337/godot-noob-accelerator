# Godot Noob Accelerator (plugin)

The process layer for making a Godot 4 game with Claude Code. Run `/godot-accel:bootstrap` in
a Godot project to write its CLAUDE.md, rules, memory and docs skeleton; then the `resume`,
`plan-feature`, `ship-check`, `save-work`, `trim-context`, `workflow-audit`, `canon-check` and
`harvest-learnings` skills, three reviewer agents and three portable hooks run the project session
by session. Full documentation, install steps and the beginner's guide are in the repository's
main README and `docs/` folder.

## Install

```
/plugin marketplace add dawnmaster1337/godot-noob-accelerator
/plugin install godot-accel@godot-noob-accelerator
```
