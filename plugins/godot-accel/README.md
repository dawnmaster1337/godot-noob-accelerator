# Godot Noob Accelerator (plugin)

The process layer for making a Godot 4 game with Claude Code. Run `/godot-accel:bootstrap` in
a Godot project to write its CLAUDE.md, rules, memory and core docs (more appear when the game
needs them); then the `resume`, `plan-feature`, `ship-check`, `save-work`, `trim-context`,
`project-audit`, `canon-check`, `harvest-learnings`, `realign` and `update` skills, three reviewer
agents and six portable hooks run the project session
by session. Full documentation, install steps and the beginner's guide are in the repository's
main README and `docs/` folder.

## Install

```
/plugin marketplace add dawnmaster1337/godot-noob-accelerator
/plugin install godot-accel@godot-accel
```
