# Example: a bootstrapped project, a few sessions in

**Invented example.** "Lily Hop" is a made-up one-screen game (a frog hops across lily pads
before they sink) used only to show what the kit's files look like once filled in. It isn't a
real project and there's no game code here: only the docs layer.

| File | Shows |
|---|---|
| `CLAUDE.md` | A filled-in CLAUDE.md (no canon, no MCP, push on) |
| `.claude/memory/` | The index and one feedback memory with its Why and How to apply |
| `docs/STATUS.md` | A STATUS after three sessions |
| `docs/decisions/` | The index and one decision record with the user's answers |
| `docs/plans/` | The roadmap and one feature plan, half ticked |
| `docs/systems/hopping.md` | A "what is true now" page |
| `docs/known-bugs.md` | One open bug with its repro, and one fixed with its cause |
